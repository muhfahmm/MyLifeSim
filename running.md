# Command Jalankan Aplikasi

### 1. Flutter Web (Port 3100 & Otomatis Buka Browser Default - Mirip Next.js)
Jalankan script berikut di PowerShell:
```powershell
.\dev.ps1
```
*Script ini akan menjalankan web server di port 3100 dan secara otomatis membuka link `http://localhost:3100` di **Browser Default** sistem Anda (Edge, Chrome, Brave, Firefox, dll).*

### 2. Standard Flutter Web Command
```bash
flutter run -d web-server --web-port=3100
```

### 3. Flutter Desktop (Windows)
```bash
flutter run -d windows
```
