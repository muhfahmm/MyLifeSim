# Analisis Persentase Ajakan Romantis di Dalam Anggota Keluarga (Incest)

Berikut adalah tabel peluang (persentase) munculnya ajakan romantis dari atau kepada anggota keluarga sendiri (incest) berdasarkan kode sumber game.

---

## 1. NPC Keluarga yang Mengajak User (Inisiasi oleh NPC)

### A. Peluang Berdasarkan Jenis Hubungan Keluarga
Setiap anggota keluarga berusia $\ge 12$ tahun memiliki peluang individu berikut untuk mengajukan ajakan:

| Hubungan Keluarga | Persentase Peluang Mengajak | Keterangan |
| :--- | :---: | :--- |
| **Saudara Kandung (Sibling)** | 15% | - |
| **Anak Kandung** | 15% | - |
| **Mertua (Ayah/Ibu Mertua)** | 15% | - |
| **Keluarga Besar (Kakek/Nenek/Paman/Bibi)** | 15% | Kakek/Nenek hanya jika user $\ge 10$ tahun, lainnya $\ge 12$ tahun |
| **Keponakan** | 10% | Anak dari saudara kandung |

### B. Peluang Orang Tua Kandung & Tiri (Jika Orang Tua Bercerai)

| Gender User | Hak Asuh (Custody) | Ibu Kandung | Ayah Kandung | Ibu Tiri | Ayah Tiri |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **Laki-laki** | Ikut Ibu | 30% | 10% | - | 5% |
| **Laki-laki** | Ikut Ayah | 15% | 5% | 25% | - |
| **Perempuan** | Ikut Ibu | 10% | 25% | - | 40% |
| **Perempuan** | Ikut Ayah | 10% | 60% | 5% | - |

### C. Peluang Orang Tua Kandung (Jika Orang Tua Lengkap / Tidak Cerai)

| Gender User | Ibu Kandung | Ayah Kandung |
| :--- | :---: | :---: |
| **Laki-laki** | 5% | 10% |
| **Perempuan** | 10% | 25% |
