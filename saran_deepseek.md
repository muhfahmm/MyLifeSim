1. Logika Kecerdasan (Intelligence)
=> Faktor KENAIKAN (+):
- Belajar / Baca Buku
- Pengaruh Disiplin: Jika Disiplin > 70%, bonus belajar menjadi x1.5 (karena fokus maksimal).

=> Faktor PENURUNAN (-):
- Stres / Kebahagiaan Rendah: Jika Happiness < 30%, kecerdasan otomatis turun -2 s/d -4 per tahun karena sulit berkonsentrasi.
- Usia Tua (di atas 50 tahun): -1 per tahun (penuaan otak).

2. Logika Disiplin (Discipline)
=> Faktor KENAIKAN (+):
- Pengaruh Kecerdasan: Jika Kecerdasan > 70%, Disiplin naik ekstra +1 (karena otak pintar membuat strategi rutinitas yang efektif).
=> Faktor PENURUNAN (-):
- Kebahagiaan Rendah (Happiness < 30%): Disiplin turun -3 s/d -5 drastis karena hilang motivasi hidup.
- Bolos / Skipping sekolah: -2.
- Kesehatan Buruk (di bawah 30%): -1 (badan lemes jadi malas gerak).
